# Product specification

## Product
**RegOps EU — Cyber Resilience Operations Platform**

> From vulnerability to regulatory evidence in minutes — with humans in control.

## Primary users
- Product Security / PSIRT
- CISO / Security Operations
- Engineering / Product owners
- CRA compliance / GRC
- NIS2 program owners
- Legal / regulatory reviewers
- Executive incident duty managers

## Jobs to be done
1. Understand whether a vulnerability or security incident creates a regulatory reporting **candidate**.
2. See the 24h / 72h clock without spreadsheet arithmetic.
3. Know what evidence is missing.
4. Connect product/version/SBOM evidence to an incident.
5. Route review to accountable humans.
6. Produce a structured draft evidence pack.
7. Preserve an auditable decision history.

## Public MVP
- synthetic product onboarding
- CRA scope-candidate flag
- CycloneDX JSON upload and summary
- vulnerability / severe-incident signals
- deterministic CRA + NIS2 Germany screening
- 24h / 72h / final-report deadline calculation
- evidence readiness matrix
- human approval route
- JSON evidence pack export
- browser-local history
- FastAPI + SQLite reference backend
- optional advisory local-model explanation
- 30-case regression evaluation
- Docker + GitHub Actions
- cinematic Next.js command center

## Explicit non-goals
- legal advice
- autonomous regulatory submission
- claims of CRA/NIS2 applicability
- real customer/security data in the hosted demo
- live CVE exploitation claims
